WSL2 里的 Minikube IP（如 `192.168.49.2`）是内部虚拟网络，**Windows 浏览器默认访问不到**。有几种解决方案：

---

## 方案一：Port-forward（最简单，推荐）

在 WSL 终端里执行（已经内置了 make 命令）：

```bash
# 在 ldp 项目目录下
make airflow-forward    # Windows 访问 http://localhost:8080
make minio-forward      # Windows 访问 http://localhost:9001
make spark-forward      # Windows 访问 http://localhost:8080
make jupyter-forward    # Windows 访问 http://localhost:8888
make grafana-forward    # Windows 访问 http://localhost:3000
make prometheus-forward # Windows 访问 http://localhost:9090
```

**原理**：`kubectl port-forward` 把 K8s Service 端口映射到 WSL 的 `localhost:端口`，而 **WSL2 的 localhost 会自动转发到 Windows 的 localhost**。

> ⚠️ Port-forward 是前台进程，保持终端开着。按 `Ctrl+C` 停止。

---

## 方案二：通过 WSL2 IP 直接访问

如果方案一的 localhost 不通，可以用 WSL2 的 IP 地址访问：

### 1. 获取 WSL2 IP

```bash
# 在 WSL 终端执行
hostname -I | awk '{print $1}'
# 或
ip addr show eth0 | grep "inet " | awk '{print $2}' | cut -d/ -f1
```

假设输出是 `172.22.16.2`。

### 2. 用 `--address` 绑定到所有网卡

以 Airflow 为例：

```bash
kubectl port-forward -n ldp svc/airflow-webserver 8080:8080 --address=0.0.0.0
```

然后 Windows 浏览器访问：
```
http://172.22.16.2:8080
```

---

## 方案三：Minikube Service 命令（自动开隧道）

Minikube 自带一个命令可以为 NodePort 服务创建可访问的 URL：

```bash
# Airflow
minikube service airflow-webserver -n ldp

# MinIO
minikube service minio-console -n ldp

# Spark
minikube service spark-master-svc -n ldp

# Jupyter
minikube service jupyter -n ldp
```

执行后会自动在 Windows 默认浏览器打开对应页面。

---

## 方案四：批量端口转发脚本

如果你不想一个个执行，可以写一个后台脚本，一次性转发所有服务：

```bash
# 在 WSL 里创建脚本
cat > ~/ldp-port-forward.sh << 'EOF'
#!/bin/bash
kubectl port-forward -n ldp svc/airflow-webserver 8080:8080 &
kubectl port-forward -n ldp svc/minio-console 9001:9001 &
kubectl port-forward -n ldp svc/spark-master-svc 8081:8080 &
kubectl port-forward -n ldp svc/jupyter 8888:8888 &
kubectl port-forward -n ldp svc/grafana 3000:3000 &
kubectl port-forward -n ldp svc/prometheus 9090:9090 &
echo "All ports forwarded!"
echo "Airflow:    http://localhost:8080"
echo "MinIO:      http://localhost:9001"
echo "Spark:      http://localhost:8081"
echo "Jupyter:    http://localhost:8888"
echo "Grafana:    http://localhost:3000"
echo "Prometheus: http://localhost:9090"
EOF

chmod +x ~/ldp-port-forward.sh
~/ldp-port-forward.sh
```

然后 Windows 浏览器直接用 `localhost` + 对应端口访问。

> 停止所有转发：`killall kubectl`
